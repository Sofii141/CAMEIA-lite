# Registro de las sesiones

Aquí va la evidencia que sale del código (los datos de medición siguen en la bitácora xlsx de la carpeta de la entrega):

- `sorteo_<semilla>.txt`: la salida de `python sorteo.py <semilla>`.
- Commits por tarea: `tNN: inicio`, `tNN: terminado`, `tNN: retrabajo`. Con ellos se calcula el retrabajo desde `git log`.
- Si una tarea se descarta (por ejemplo, porque alguien abrió las pruebas ocultas antes de tiempo), se anota aquí con la marca `[C]`.
