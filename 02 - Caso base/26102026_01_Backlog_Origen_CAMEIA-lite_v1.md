# Backlog de origen de CAMEIA-lite — v1

**Para qué sirve:** muestra de qué ítem real de CAMEIA (Jira CM-xx y su pull request fusionado) sale cada una de las 24 tareas del caso base, y qué se simplificó.

**Cómo se construyó:** con los PR fusionados a `develop` de los 9 repos de CAMEIA, extraídos con `gh pr list` el 25/10/2026 (324 PR; se excluyeron Dependabot y los PR de la pareja salvo donde se indica). Cada tarea aísla **una** regla del PR como función pura, sin infraestructura.

**Marcas:**
- `[V]` está en el PR enlazado.
- `[P]` es una regla añadida o ajustada por nosotros para hacer el caso difícil; no está textual en CAMEIA.
- `[N]` el dato no consta.

**Limitación:** casi todos los PR de origen se escribieron con Claude Code (llevan la etiqueta `[IA-ASISTIDO]`). La regla de negocio viene del backlog real, pero la forma de la solución original puede tener "estilo de agente".
